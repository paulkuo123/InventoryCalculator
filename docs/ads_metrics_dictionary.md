# 廣告指標詞典

## 核心欄位

- `銷售數`：顧客點擊該商品廣告後，後續所有相關訂單帶來的商品總銷售數量。
- `直接銷售數`：顧客點擊該商品廣告後，直接購買同一商品的總銷售數量。
- `銷售金額`：顧客點擊該商品廣告後，後續所有相關訂單帶來的總銷售金額。
- `直接銷售金額`：顧客點擊該商品廣告後，直接購買同一商品帶來的總銷售金額。
- `轉換數`：點擊廣告後發生的全部轉換數，含直接與間接轉換。
- `直接轉換數`：點擊廣告後直接購買同一商品的轉換數。
- `投入產出比`：總 ROAS，使用 `銷售金額 / 花費`。
- `直接投入產出比`：直接 ROAS，使用 `直接銷售金額 / 花費`。
- `成本收入比率`：總 ACOS，代表花費占銷售金額比例。
- `直接成本收入比率`：直接 ACOS，代表花費占直接銷售金額比例。

## 解讀原則

- 「總」指標適合看整體廣告貢獻。
- 「直接」指標更適合判斷單一商品廣告是否真的帶來直接成交。
- 若總 ROAS 明顯高於直接 ROAS，代表該商品廣告可能更偏向輔助成交，不應只看總體回收就加碼。
- 若直接 ROAS 穩定高、花費也穩定增加，才適合評估是否擴量。
