# 廣告分析規則

## 立即加碼

- 近一週或近一月花費已達顯著水位。
- 直接 ROAS 高於 2.5，總 ROAS 高於 3.0。
- 轉換數與點擊量具備足夠樣本。
- 今日表現沒有明顯劣化。
- 建議措辭：先檢查是否觸及預算上限，若常態跑滿可逐步提高預算或放寬目標。

## 優先降預算

- 已投入顯著花費。
- 直接 ROAS 長期低於 1.5，且總 ROAS 也偏弱。
- 今日與近一週的回收都沒有改善。
- 建議措辭：先控制花費、收緊出價、檢查商品頁轉換率與素材。

## 依賴間接轉換

- 總 ROAS 看起來不差，但直接 ROAS 明顯偏弱。
- 直接銷售金額占總銷售金額比重過低。
- 建議措辭：不要只看總體 ROAS，應優先確認直接回收是否足夠穩定。

## 持續觀察

- 今日表現短期轉強，但時間還不夠長。
- 或流量樣本偏小，但 ROAS 不差。
- 建議措辭：先維持投放並連續觀察 2 至 3 天，再決定是否擴量或收縮。

## 保持

- 沒有明顯異常，也沒有明顯擴量訊號。
- 建議措辭：維持現況，持續追蹤直接 ROAS、花費與點擊量變化。
