# ai_reviewed 第 2 層弱區（#120 之後）

起點是 `d32967a`（#120）。全表核准評估裡，`ai_reviewed` 仍約 Top-1 47.7%、FN 37.1%（310 列可評）。吊飾全表 FN 仍約 47.7%。#120 已處理包裝數量、襪子丹尼、毛絨填詞；這一刀不加寬那些規則，也不加寬 #119 的裸殼降權。

本環境沒有 `procurement.db`，不能重跑 sample500 或全表。下面只靠合成測。

不寫 Golden、不開 `auto_approve`、不為單一 SKU 或貨號寫死別名。仍走原來的 `generate_candidates()`，沒有第二套 matcher。

## 這一刀做了什麼

| 規則 | 範圍 | 效果 |
|---|---|---|
| 夾片／掛繩套話 | 只在類別 `charm` | 比較前去掉 `薄至…mm`、`注塑`、`一體成型`／`一體注塑`、`d扣`／`d扣·`、開頭 `#10` 或 `7#` 這類索引。`可調掛繩` 只去掉 `可調`，`掛繩` 留下。型號寫了掛繩，候選也要有掛繩；只寫夾片時，同色但多了掛繩的列會排在後面。`夾片` 只在還留得下色名時才當填詞 |
| 尺碼字母 | 全部類別，只限整段 token | `S`↔`小號`、`M`↔`中號`、`L`↔`大號`。逗號分開的那一格必須整格就是字母。`S29`、`sl061`、`s-29` 這種型號裡的 S 不改寫 |

吊飾裡，至少三個字、而且以「色」結尾的 token，比較前會拿掉最後那個「色」。所以 `深灰色` 對得上 `深灰`，`酒紅色` 對得上 `酒紅`。兩個字的 `灰色`、`藍色`、`白色`、`紫色` 不動。其他類別仍把 `奶茶` 和 `奶茶色` 分開。沒有新增色系同義詞。

## 合成測

| 例子 | 結果 |
|---|---|
| `深灰色掛繩+透明夾片` ↔ `【#10深灰】可調掛繩+一體注塑夾片` | Top-1。同清單裡的酒紅掛繩不會搶 |
| `酒紅夾片` ↔ `薄至0.6mm【d扣·酒紅色】注塑一體成型` | Top-1。同色的 `#11酒紅` 掛繩列還在窗裡，但排在後面 |
| `S`／`M`／`L` ↔ `小號`／`中號`／`大號` | 整段 token 對得上；`小號` 也能對回 `S` |
| `S29`、`sl061` | 不會收成小號 |
| `紫色`／`紫色夾片` 對 `丁香紫` | 不合 |
| `白色`／`白色夾片` 對 `象牙白` | 不合 |
| `藍色夾片` 對 `宝石蓝`、`暖黃夾片` 對 `暖陽黃` | 不合 |
| `可愛獺兔毛球` 對 `煤球大白眼` | 仍不合（#120 的負例還在） |

## 明確不做

- 不把 `紫色` 收成 `丁香紫`、`白色` 收成 `象牙白`、`橙色` 收成 `愛瑪橙`、`藍色` 收成 `宝石蓝` 或 `海藍色`、`暖黃` 收成 `暖陽黃`。
- 不把 `淺灰`→`灰`、`彩色`→`混彩`、`天藍`→`藍`、`亮紅`→`玫紅`。
- 不把 `獺兔毛球` 對到 `煤球大白眼`。
- 不把沒寫丹尼的 1688 名稱補成 `0D`。
- 不把 `不鏽鋼` 併成 `鐵質`。
- 不建 `YSK`↔`qy-ysk` 貨號表。
- 不把 `陶瓷狗掌繩` 收成 `陶瓷狗掛繩`。
- 不加寬 #119 裸殼／掛繩降權，不改手機殼的機型層級。
- `黑色夾片` 對 `經典黑`、`透明夾片` 對 `全透明`、`藏藍色` 對 `藏青` 仍不是這一刀的規則。色名要整段對得上，或只差既有的尾端「色」。

## 下一條殘餘

1. 夾片色名本身不同（丁香紫、象牙白、愛瑪橙、宝石蓝、暖陽黃、經典黑、全透明）繼續留給人，不要為了抬 FN 去縮色。
2. 毛絨側還有獺兔毛球、淺灰／彩色／天藍／亮紅，以及毛毛蟲的頭尾叫法。造型名不同就不要併。
3. 0D 黑絲、不鏽鋼對鐵質、貨號表、陶瓷狗掌繩，維持空候選。
4. 有 `procurement.db` 之後，用 #120 全表當 baseline 再看 `ai_reviewed` 的 Top-1 與 FN。綠燈變差，或夾片只多到錯色，就縮回套話剝除，不要動裸殼降權和機型層級。
